Privacy Policy

Last updated: 13 October 2026

This privacy policy describes how the personal automation application ("the Application") handles data. The Application is a private, single-user tool operated by its owner, Andrey Melnikov, for his own use.

Who uses the Application

The Application has exactly one user: its owner. It is not offered to the public, has no other accounts, and no third party can sign in.

What data is accessed

With the owner's explicit consent, the Application may access the following Google Workspace data belonging to the owner's own Google Account:

  • Gmail — messages, threads, labels, and settings
  • Google Calendar — calendars and events
  • Google Drive — files and metadata
  • Google Docs, Sheets, and Slides — document content
  • Google Contacts — contact records

How data is used

Data is accessed only to perform tasks the owner requests — for example, reading email, checking a calendar, or searching for a file. Data is processed locally on the owner's own device.

Data sharing

Data is never sold, rented, or shared with third parties. No data is used for advertising, profiling, or training machine-learning models. The Application does not transfer data to any external server other than the Google APIs required to fulfil the owner's request.

Data storage and retention

The Application stores OAuth credentials locally on the owner's device so it can reconnect without repeated sign-in. It does not maintain its own database of message or file contents beyond what is needed to complete a task. The owner can revoke access at any time.

Security

Credentials are kept in the operating system's secure keychain. Access tokens are short-lived and refreshed automatically. No credentials are shared with third parties.

Revoking access

The owner may revoke the Application's access at any time at myaccount.google.com/permissions.

Changes

This policy may be updated from time to time. The current version is always available at this address.
